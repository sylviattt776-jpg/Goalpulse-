# GoalPulse ⚽

Every Goal. Every Moment.

A football scores website with Home, Fixtures, Leagues and Favourites sections.

## Current status
This package contains the current GoalPulse front-end. Match entries are demo data, not live scores. The SportAPI connection has not yet been added.

## Publish
Upload `index.html` and `README.md` to the root of the `goalpulse` GitHub repository. Do not put any API key in these files or in GitHub.
